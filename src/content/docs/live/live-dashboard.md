直播时如果同时开着网页看弹幕、看后台礼物、切歌、开投票，窗口一多很快就会手忙脚乱。**直播中控台（`/live-dashboard`）** 把开播最常用的盯屏信息全部塞进一个可自由拖拽分栏的整屏面板里。

## 四栏布局与自由定制

* **四个独立面板**：弹幕流、醒目留言与礼物（付费事件）、弹幕投票监控等栏目可以根据你的屏幕比例用鼠标拖曳分隔条调整宽度，也可以把暂时不看的面板隐藏掉。
* **专注模式（局部虚化）**：如果你需要临时把中控台拖到直播画面里给观众看某个功能，可以开启专注虚化，把敏感面板或局部用户信息糊掉防泄露。
* **右键快捷菜单**：在单条弹幕上右键可以直接复制用户名、标记重点或执行快捷互动处理。

## 几个很顺手的快捷键

| 快捷键 | 作用 | 说明 |
| :--- | :--- | :--- |
| `Alt + M` | **记录高光时刻** | 直播里刚发生搞笑/精彩片段时按一下，下播去「直播记录」能直接定位这个时间点切片 |
| `1` ~ `4`（非输入状态下） | 快速显隐对应面板 | 视口太窄时快速切栏位 |
| 顶部工具栏导出 | 保存片段长图 | 想把某段弹幕对话截图发动态时很方便 |

<DocCallout type="info" title="网页版与客户端版的区别">
  网页版 <code>/live-dashboard</code> 与桌面客户端里的中控台共用核心界面。在桌面客户端里使用时，会额外解锁<strong>直接发送弹幕回复</strong>、<strong>顶栏朗读状态控制</strong>以及<strong>本地 OBS 速控</strong>能力。
</DocCallout>
