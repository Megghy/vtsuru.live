后台里同时有 **点歌机（歌势）** 和 **弹幕点播** 两个页面，很多朋友刚来时会有点疑惑它们俩有什么区别——简单说：**唱给自己听用「点歌机」，放给直播间听用「点播」。**

## 两个功能怎么选

| 维度 | 点歌机 / 歌势 (`manage-musicRequest`) | 弹幕点播 (`manage-liveRequest`) |
| :--- | :--- | :--- |
| **核心用途** | 歌回直播，观众从**你的个人歌单曲库**里挑歌让你唱 | 杂谈、游戏间隙，弹幕**搜索放歌或 B 站视频**直接播 |
| **曲目来源** | 联动你的公开歌单与待唱列表 | 在线音乐/视频搜索直放 |
| **互动门槛** | 可设粉丝牌等级、舰长免费/优先插队规则 | 可配置点播消耗与冷却、今日已处理清单 |
| **OBS 画面** | 专用歌回排队列表源（`/obs/music-request`） | 主播放器源（`/obs/live-request`）+ 今日已处理列表（`/obs/live-request-today`） |

## 歌回直播常用顺手配置

1. **先把歌单填好**：去「歌单」页面导入或批量录入拿手曲目（支持从文件导入），观众在你的公开主页歌单页还能直接一键复制点歌弹幕口令。
2. **设置牌子与舰长策略**：歌回人多点不过来时，可以限制最低粉丝牌等级，或者给大航海开放自动插队权。
3. **OBS 挂上排队进度**：把 `/obs/music-request` 贴进 OBS 的歌回场景里，唱完一首勾掉一首，观众随时能看前面还有几首、下一首是谁点的。

<DocCallout type="info" title="弹幕点播别忘了开 OBS 音频控制">
  使用弹幕点播在 OBS 源里直放视频/音乐时，务必勾选 OBS 浏览器源的「通过 OBS 控制音频」，这样你可以在推流混音器里随时调节背景音乐音量，避免盖住说话声。
</DocCallout>
