## 1. 弹幕排队（`/manage/queue`）

做连麦水友赛、看号、或者帮观众看抽卡时，不用拿记事本手记 ID 了：

* **入队门槛**：支持设置关键词触发入队，同时支持**粉丝牌等级、指定礼物、大航海身份**等条件筛选。
* **公开队列状态 + OBS 展示**：除了管理端一键叫号/完成/移除，还带 `/obs/queue` 浏览器源，直接把当前轮到谁、后面还排了几位投屏到画面上。

## 2. 弹幕投票（`/manage/vote`）

* **随时发起与预设模板**：常玩的几套选项（比如“打哪张图”“接下来干嘛”）可以存成模板，下次直接一键发起。
* **灵活控场**：支持**延长倒计时、临时暂停计票**；如果观众打错了相近选项，后台支持直接**把两个选项合并**计票，遇到平局还能一键现场抽签决定胜负。
* **多端同步**：投票面板不仅能放在 `/obs/danmaku-vote` 投屏，还能直接嵌在直播中控台与个人公开主页上。

## 3. 两种抽奖玩法

* **直播间实时抽奖（`/manage/live-lottery`）**：抓直播间当前发送指定口令弹幕、或送出指定礼物的在线观众，搭配 `/obs/live-lottery` 开奖挂件搞定现场抽奖。
* **动态评论/转发抽奖（`/manage/lottery`）**：把 B 站动态链接贴进去，一键拉取评论和转发名单，按关注/去重等条件过滤后开奖并留存结果记录，适合下播后的动态福利活动。
