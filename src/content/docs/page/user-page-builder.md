## 四种页面模式按需切换

在编辑器的页面配置里，每个子页面都可以选四种模式之一：

1. **可视化自由搭建（主力推荐）**：拖拽并调整列宽比例，用 **44 种现成积木区块**拼出任意布局。
2. **经典模板 / 扩展组件页**：懒得排版时可以直接套用经典预设，或直接把歌单/日程/提问箱挂成独立 Tab。
3. **自定义代码页（Vue SFC 沙盒）**：如果你自己懂一点前端，可以直接在内置 Monaco 编辑器里写 Vue 单文件组件！沙盒自带主题 CSS 变量和 `vtsuru` 宿主 SDK（支持 `vtsuru.getSongs()` 等方法读取公开数据），想做什么酷炫动效都能实现。

## 常用的几类积木区块

* **人设与设定**：OC 角色立绘展示、人物关系/Tag、色卡板（观众/画师约稿直接取色超方便）、背景故事卡片。
* **实用与互动**：**声按钮语音板**（放上“早安呀”“awa”等音频切片点一下就出声）、约稿价目表与排单状态、社交链接、文字动画（渐变/发光/彩虹/打字机）。
* **站内数据联动**：自动实时拉取 B 站开播状态、最近排班日程、公开歌单与棉花糖入口。

<DocCallout type="tip" title="手机与桌面双端预览">
  编辑器预览区右上角可以随时切换「手机 / 平板 / 桌面」三种视口，配好桌面端之后顺手切手机看一眼，确保移动端粉丝点开也不乱版。
</DocCallout>
