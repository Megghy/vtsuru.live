刚开始只做了几个常用小挂件，后来自己直播或朋友提需求时越加越多，现在 **OBS 组件库（`/manage/obs-store`）** 里已经攒了二十多个独立纯前端透明挂件。每个挂件都有自己的控制台和 OBS 展示地址，也能直接拖进场景编辑器里组合。

下面先挑三个最常用的挂件，你可以**直接在网页里点按钮体验**实时反馈：

## 实时可交互体验

### 1. 受苦挑战计数器

打魂游、受苦平台跳跃或者刷成就时用起来特别顺手，支持网页点击或全局快捷键 `+1 / -1`。

<DocObsDemo kind="counter" />

### 2. 舰长 / 营收目标与耐久加钟

绑定直播间目标后，收到礼物、SC 或新上舰时进度条会自动推进，还可以顺带给耐久加钟倒计时续时间。

<DocObsDemo kind="goal" />

### 3. 时钟与倒计时（14 套精选预设）

收录了瑞士极简、辉光管、卡西欧、点阵、像素、战术风格等十多种预设，开播倒计时、速通正计时和日常时钟都能切换。

<DocObsDemo kind="clock" />

## 21 款实装挂件分类速查

| 分类 | 组件名称 | 一句话说明 |
| :--- | :--- | :--- |
| **外设输入** | 游戏手柄投屏 (`gamepad`) | 低延迟显示 Xbox / PS / Switch 按键、双摇杆偏移与线性扳机 |
| **外设输入** | 键鼠按键投屏 (`keycast`) | 实时显示键盘组合键与鼠标动作，音游、FPS、画画/教程直播很直观 |
| **外设输入** | 打字猫 (`typing-cat`) | 跟着你的键盘敲击实时拍爪子、换配饰的小猫桌面宠物 |
| **互动与氛围** | 物理大转盘 (`wheel`) | 带阻尼手感的 Canvas 大转盘，后台点一下即可同步在 OBS 开奖 |
| **互动与氛围** | 直播盲盒 (`mystery-box`) | 抽取盲盒奖励并展示开盒动效 |
| **互动与氛围** | 表情弹幕雨 (`emote-hype`) | 观众刷起表情时在画面里飘起表情雨 |
| **互动与氛围** | 提醒弹窗 (`alert-box`) | 礼物、大航海、SC 触发的自定义入场提示弹窗 |
| **直播信息** | 实时语音字幕条 (`subtitle`) | 接上桌面端本地语音转写，低延迟滚动显示字幕 |
| **直播信息** | 直播状态 HUD (`live-hud`) | 紧凑展示当前直播状态与互动数据条 |
| **直播信息** | 礼物看板 (`gift-board`) / 当前播放 (`now-playing`) | 展示礼物统计或正在播放的歌曲信息 |
| **直播信息** | 日程条 (`schedule`) / 待办清单 (`checklist`) | 把本周排期或今天直播待办清单直接钉在画面一角 |
| **直播信息** | 积分展示 (`point-showcase`) / 歌单点播 (`song-picker`) / 视频征集 (`video-collect`) | 把站内积分活动、选歌与征集进度投屏给观众看 |
| **虚拟形象** | PNGtuber (`pngtuber`) / 多人连麦头像 (`voice-avatars`) | 麦克风驱动双图反应立绘与多人连麦亮灯头像（另见专门文档） |

<DocCallout type="tip" title="浏览器与桌面端同步机制">
  在组件库控制台里调完参数后，可以通过频道同步或一键复制专属 OBS 链接让 OBS 源实时更新，不用每次改动都手动重新粘贴链接。
</DocCallout>
